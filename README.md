# ro-maji IME Rescue — サイト

Windows 常駐ツール **ro-maji IME Rescue** の公開サイトです。GitHub Pages で配信しています。

IME をオフにしたまま打ってしまったローマ字を、変換キーひとつで日本語に入力し直すツールです。

## ページ

| ファイル | 内容 |
|---|---|
| `index.md` | トップページ。アプリ紹介・使い方・サポート連絡先 |
| `troubleshooting.md` | 症状別の切り分け手順 |
| `privacy.md` | プライバシーポリシー |

## 補足

このリポジトリにはサイトの内容のみを置いています。アプリのソースコードは含まれません。
